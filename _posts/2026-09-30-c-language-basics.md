这篇文章写给**完全没接触过 C 语言**的人。目标不是让你"看过一遍"，而是让你**能自己写出一个能跑的小程序**。

全文按"能动手"的顺序组织：先装环境跑通第一个程序，再一个个补上语法零件，最后用练习题把它们串起来。每一段代码都可以直接复制去编译运行，建议你边看边敲。

阅读建议：

- 第一次读，不要试图背下所有细节，先理解"这段代码在干什么"；
- 看到不理解的地方，动手改一改数字、删掉一行，看编译器报什么错，这比死记快得多；
- 全文的代码都在同一套约定下编写：C17 标准、`gcc -Wall -Wextra` 编译无警告。

## 一、动手之前：把环境装好

### 1.1 C 语言是怎么变成程序的

写 C 语言和写 Python、JavaScript 不一样：**C 代码不能直接运行，必须先被"编译"成机器能懂的二进制文件**。

这个过程叫编译，它其实分了四步：

```text
hello.c  ──预处理──▶  hello.i  ──编译──▶  hello.s  ──汇编──▶  hello.o  ──链接──▶  hello
 源码                  展开后的代码         汇编代码          目标文件          可执行文件
```

你平时只需要敲一条命令，这四步会自动完成。之所以先讲这一步，是因为新手最常遇到的困惑就是"我代码明明没问题，怎么运行不了"——**多半是卡在"忘了编译"或者"编译报错了但没看提示"**。

### 1.2 安装编译器

你需要的只有一个东西：**编译器**。推荐 GCC。

**Windows**

三种选择，任选一种：

1. **MSYS2**（推荐）：到 msys2.org 下载安装，然后在 MSYS2 终端里执行 `pacman -S mingw-w64-ucrt-x86_64-gcc`。
2. **MinGW-w64**：下载解压后，把 `bin` 目录加进系统环境变量 `PATH`。
3. **Visual Studio**：安装时勾选"使用 C++ 的桌面开发"，它会自带 `cl.exe` 编译器。

装完打开终端（命令提示符或 PowerShell），输入：

```bash
gcc --version
```

如果输出了版本号，就成功了。

**macOS**

打开终端执行：

```bash
xcode-select --install
```

这会装好苹果的 Clang 编译器（用法和 gcc 基本一致）。

**Linux**

```bash
sudo apt install build-essential      # Debian / Ubuntu
sudo dnf install gcc make             # Fedora
```

### 1.3 第一个程序：Hello, World!

新建一个文件，名字叫 `hello.c`。注意后缀必须是 `.c`，不能是 `.txt`。

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

### 1.4 编译并运行

在终端里进入这个文件所在的目录，执行：

```bash
gcc -Wall -Wextra -std=c17 hello.c -o hello
```

这条命令的意思是：用 C17 标准编译 `hello.c`，打开所有常用警告，输出一个叫 `hello` 的可执行文件。

然后运行它：

```bash
./hello          # macOS / Linux
hello.exe        # Windows
```

屏幕上会输出：

```text
Hello, World!
```

**这里有个新手必踩的坑**：每次修改代码后，都必须**重新编译一次**。直接运行旧的 `hello.exe` 是不会看到新结果的。

顺便解释一下 `-Wall -Wextra` 这两个参数。它们不是可有可无的装饰，而是**你最好的老师**：C 语言有很多"语法上合法但行为可疑"的写法，编译器默认不吭声，加上警告之后它会明确告诉你哪里可能有问题。从一开始就养成带上它们的习惯。

### 1.5 逐行拆解这个程序

```c
#include <stdio.h>          // ① 引入标准输入输出库
                            
int main(void) {            // ② 主函数，程序的入口
    printf("Hello, World!\n");   // ③ 调用 printf 打印一行字
    return 0;               // ④ 告诉操作系统：程序正常结束
}
```

**① `#include <stdio.h>`**

`stdio` 是 standard input/output（标准输入输出）的缩写。`printf` 这个函数就声明在这个头文件里。**不写这一行，编译器不认识 `printf`。**

注意：它**不是**可执行语句，所以结尾不加分号。

**② `int main(void)`**

`main` 是程序的唯一入口。操作系统运行你的程序时，就是从 `main` 的第一行开始执行的。

- `int` 表示这个函数会返回一个整数；
- `void` 在括号里表示"这个函数不接受任何参数"；
- `{` 和 `}` 之间是函数体。

**③ `printf("Hello, World!\n");`**

`printf` 负责往屏幕上输出文字。

- 字符串用双引号包起来；
- `\n` 是**换行符**，它让光标移到下一行。你可以试着删掉它，会看到输出结果和终端提示符挤在同一行；
- 结尾的**分号**不能少。C 语言里每条语句都以分号结尾。

**④ `return 0;`**

把 0 返回给操作系统，表示"程序成功结束了"。按惯例，返回 0 代表成功，返回非 0 代表出错。

## 二、注释与代码风格

### 2.1 两种注释

```c
// 这是单行注释，从 // 开始到这一行结束

/*
   这是多行注释，
   可以跨很多行。
*/
```

注释不会被编译，纯粹写给人看。**新手最该养成的习惯是：在"为什么这么写"的地方留注释，而不是在"这行做了什么"的地方写废话。**

比如这种注释没有价值：

```c
i = i + 1;   // i 加 1
```

而下面这种是有价值的：

```c
i = i + 1;   // 数组下标从 0 开始，这里跳到下一个元素
```

### 2.2 几条让代码好读的约定

1. **缩进用 4 个空格**，不要用 Tab（不同编辑器显示宽度不一样，代码会歪）。
2. **大括号独立成行或者跟在行尾都可以，但全文要统一**。本文统一用 K&R 风格（左括号跟在行尾）。
3. **运算符两边加空格**：`a = b + c;` 比 `a=b+c;` 好读得多。
4. **变量名要有意义**：`sum`、`count`、`max_value` 远好于 `a`、`b`、`x1`。

## 三、变量与数据类型

### 3.1 变量：给内存里的格子起名字

你可以把内存想象成一排带编号的储物柜。**变量就是给某个柜子贴上一个名字标签**，之后你就可以通过这个名字存取里面的东西。

```c
int age = 18;
```

这行做了三件事：申请一个能装整数的柜子（`int`）、给它贴标签 `age`、往里放 18。

### 3.2 基本数据类型

C 语言的基本类型不多，常见的就这么几个：

| 类型 | 典型大小 | 能表示的范围 | 用途 |
| --- | --- | --- | --- |
| `char` | 1 字节 | -128 ~ 127 | 单个字符，或很小的整数 |
| `short` | 2 字节 | -32768 ~ 32767 | 省内存的小整数 |
| `int` | 4 字节 | -21 亿 ~ 21 亿 | **最常用的整数类型** |
| `long` | 4 或 8 字节 | 依平台而定 | 更大的整数 |
| `long long` | 8 字节 | 约 ±9.2×10¹⁸ | 非常大的整数 |
| `float` | 4 字节 | 约 6~7 位有效数字 | 小数（精度较低） |
| `double` | 8 字节 | 约 15~16 位有效数字 | **最常用的小数类型** |
| `char` 数组 | — | — | 字符串 |

每一种整数类型前面都可以加 `unsigned`，表示"不要负数，把负数那部分范围挪给正数"：

```c
unsigned int count = 4000000000u;  // 能存到约 42 亿（u 后缀表示这是无符号常量）
```

**两个必须记住的点：**

第一，**上表的"典型大小"不是标准保证的**。C 标准只规定了 `char` 是 1 字节，以及 `short ≤ int ≤ long ≤ long long` 这个大小关系。在绝大多数电脑上 `int` 是 4 字节，但换到某些嵌入式平台上可能是 2 字节。所以**不要假设大小**，需要精确控制时用 `sizeof` 去问（见 3.6 节）。

第二，**新手平时只需要用 `int`、`double`、`char` 和字符数组**。看到 `short`、`long` 不用慌，它们是内存紧张或者数值特别大时才用的。

### 3.3 声明与初始化

```c
int a;              // 只声明，不赋值 —— a 里面是"垃圾值"！
int b = 10;         // 声明并初始化
int c = 3, d = 4;   // 一行声明多个
```

**第一条是新手最容易翻车的地方。** 局部变量如果不初始化，它里面的内容是内存里残留的随机数据，不是 0。打印出来可能是一串莫名其妙的数字。**规则很简单：声明变量时就顺手给它一个初值。**

```c
int sum = 0;        // 累加之前清零
double avg = 0.0;
```

### 3.4 命名规则

变量名必须遵守：

- 只能由**字母、数字、下划线**组成；
- **不能以数字开头**：`2count` 是错的，`count2` 是对的；
- **区分大小写**：`Count` 和 `count` 是两个不同的变量；
- 不能是 C 语言的关键字（`int`、`if`、`return` 这些）。

推荐用小写字母加下划线的风格：

```c
int student_age = 18;
double average_score = 92.5;
```

### 3.5 常量：不希望被修改的值

有两种写法。

**第一种：`const`（推荐）**

```c
const double PI = 3.14159;
// PI = 3.14;   // 错误！const 变量不能被修改
```

**第二种：`#define` 宏**

```c
#define MAX_SIZE 100

int arr[MAX_SIZE];
```

两者的区别：

- `const` 有类型，编译器会帮你检查类型错误，**优先用它**；
- `#define` 是纯粹的文本替换，在编译之前就完成了，没有类型检查。它主要用于定义数组长度、条件编译开关（见第十二章）。

### 3.6 sizeof：一个类型占多少字节

```c
#include <stdio.h>

int main(void) {
    printf("char        : %zu 字节\n", sizeof(char));
    printf("int         : %zu 字节\n", sizeof(int));
    printf("long        : %zu 字节\n", sizeof(long));
    printf("double      : %zu 字节\n", sizeof(double));

    int arr[10];
    printf("arr 总大小  : %zu 字节\n", sizeof(arr));
    printf("arr 元素个数: %zu\n", sizeof(arr) / sizeof(arr[0]));
    return 0;
}
```

在一台 64 位 Linux 机器上会输出：

```text
char        : 1 字节
int         : 4 字节
long        : 8 字节
double      : 8 字节
arr 总大小  : 40 字节
arr 元素个数: 10
```

注意 `%zu` 这个格式符——`sizeof` 的结果类型是 `size_t`，用 `%d` 打印在 64 位系统上会出错。

`sizeof(arr) / sizeof(arr[0])` 是**求数组长度的标准写法**，一定要记住。它的原理是：总字节数 ÷ 单个元素的字节数 = 元素个数。这个技巧**只在数组所在的函数内有效**，数组作为参数传给函数后会失效（第八章会解释原因）。

## 四、输入与输出

### 4.1 printf：往屏幕上写

```c
#include <stdio.h>

int main(void) {
    int age = 18;
    double score = 92.5;
    char grade = 'A';

    printf("年龄：%d 岁\n", age);
    printf("成绩：%.1f 分\n", score);
    printf("等级：%c\n", grade);
    return 0;
}
```

输出：

```text
年龄：18 岁
成绩：92.5 分
等级：A
```

**`printf` 的工作方式是：字符串里的 `%d` 这类占位符，会被后面依次传入的值替换掉。** 占位符的个数和顺序必须和后面的参数一一对应。

### 4.2 转义字符

有些字符没法直接写在字符串里，要用反斜杠转义：

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符（对齐用） |
| `\\` | 一个反斜杠 |
| `\"` | 一个双引号 |
| `\'` | 一个单引号 |
| `\0` | 空字符（字符串结束标志，见第七章） |
| `%%` | 一个百分号 |

百分号要特别注意：想打印 `100%`，必须写：

```c
printf("完成度：100%%\n");
```

### 4.3 格式说明符对照表

这张表值得贴在显示器边上：

| 说明符 | 对应的类型 | 例子 |
| --- | --- | --- |
| `%d` | `int` | `printf("%d", 42);` |
| `%u` | `unsigned int` | `printf("%u", 42u);` |
| `%ld` / `%lld` | `long` / `long long` | `printf("%lld", 123456789012LL);` |
| `%f` | `float` / `double` | `printf("%f", 3.14);` |
| `%c` | `char` | `printf("%c", 'A');` |
| `%s` | 字符串 | `printf("%s", "hello");` |
| `%x` / `%X` | 十六进制 | `printf("%x", 255);` → `ff` |
| `%o` | 八进制 | `printf("%o", 8);` → `10` |
| `%p` | 指针地址 | `printf("%p", &age);` |
| `%zu` | `size_t`（`sizeof` 的结果） | `printf("%zu", sizeof(int));` |
| `%%` | 百分号本身 | `printf("50%%");` |

**最容易搞错的一个点：`double` 类型在 `printf` 里用 `%f`，但在 `scanf` 里必须用 `%lf`。** 这个不对称的设计坑了无数人，记牢它。

### 4.4 控制宽度和小数位

```c
printf("%d\n", 42);        // 42
printf("%5d\n", 42);       // "   42"  右对齐，宽度 5
printf("%-5d|\n", 42);     // "42   |" 左对齐
printf("%05d\n", 42);      // 00042    补零
printf("%.2f\n", 3.14159); // 3.14     保留 2 位小数
printf("%8.2f\n", 3.14159);// "    3.14"
printf("%.3s\n", "hello"); // hel      只取前 3 个字符
```

输出对齐的表格时，`%-10s` 加 `%5d` 这种组合非常有用：

```c
printf("%-10s%5d\n", "apple", 92);
printf("%-10s%5d\n", "pear", 88);
```

输出：

```text
apple        92
pear         88
```

**但中文的对齐要特别小心**：`printf` 的宽度是按**字节**算的，不是按屏幕列数。一个汉字在 UTF-8 里占 3 个字节，屏幕上却只占 2 列，所以用 `%-10s` 打印中文时，实际显示宽度和你想的对不上：

```c
printf("%-10s|%d\n", "语文", 92);       // "语文" 占 6 字节，补 4 个空格
printf("%-10s|%d\n", "数学分析", 88);   // 12 字节，超过 10，一个空格都不补
```

两行的 `|` 落不到同一列上。**所以用 `printf` 对齐中文表格很容易翻车**，涉及中文时建议改用 `\t` 制表符，或者干脆输出 Markdown 表格。

### 4.5 scanf：从键盘读入

```c
#include <stdio.h>

int main(void) {
    int age;
    double height;

    printf("请输入年龄：");
    scanf("%d", &age);
    printf("请输入身高（米）：");
    scanf("%lf", &height);

    printf("你 %d 岁，身高 %.2f 米\n", age, height);
    return 0;
}
```

运行效果：

```text
请输入年龄：18
请输入身高（米）：1.75
你 18 岁，身高 1.75 米
```

**请注意 `&` 这个符号。** 它叫"取地址符"，作用是告诉 `scanf`："把这个值存到 `age` 这个变量所在的内存位置去"。

新手最常见的错误就是漏掉 `&`：

```c
scanf("%d", age);    // 错误！程序可能崩溃
scanf("%d", &age);   // 正确
```

唯一的例外是**数组名**（或者说字符串），它本身已经代表地址，所以不加 `&`：

```c
char name[20];
scanf("%19s", name);    // 不加 &
```

### 4.6 scanf 的五个坑

**坑一：`%d` 遇到字母会失败，而且不消费输入**

如果用户输入了 `abc`，`scanf` 会失败，但 `abc` 还留在缓冲区里，下一次 `scanf` 又会读到同样的 `abc`——如果你把它放在循环里，就会变成死循环。

解决办法是**检查 `scanf` 的返回值**，它等于成功读到的项数：

```c
int n;
while (scanf("%d", &n) != 1) {
    printf("输入的不是数字，请重新输入：");
    while (getchar() != '\n') { }   // 把这一行剩下的内容吃掉
}
```

**坑二：`%c` 会读到你按下的回车**

```c
int n;
char c;
scanf("%d", &n);     // 输入 5 然后按回车
scanf("%c", &c);     // c 读到的是 '\n'，不是你想输入的字符！
```

解决办法是在 `%c` 前面**加一个空格**：

```c
scanf(" %c", &c);    // 空格让 scanf 先跳过所有空白字符
```

这个技巧对 `%d`、`%s` 不用加，因为它们本身就会跳过前面的空白。

**坑三：`%s` 不检查长度，会写爆缓冲区**

```c
char name[10];
scanf("%s", name);   // 输入 20 个字符 → 内存被写坏 → 程序崩溃
```

正确写法是**指定最大宽度**（数组大小减 1，给结尾的 `\0` 留位置）：

```c
scanf("%9s", name);
```

**坑四：`%s` 遇到空格就停**

`scanf("%s", ...)` 读到空格、制表符或换行就结束。想读入"张 三"这种带空格的内容，得用 `fgets`（下一节）。

**坑五：`scanf` 和 `fgets` 混用时的换行残留**

`scanf("%d", &n)` 读完数字后，会把回车符留在缓冲区里。紧接着调用 `fgets` 读字符串，它会立刻读到这个空行，看起来就像"程序跳过了输入"。

处理办法是读完数字后手动清掉那一行：

```c
scanf("%d", &n);
while (getchar() != '\n') { }   // 清掉残留的换行
fgets(name, sizeof(name), stdin);
```

### 4.7 读一整行：fgets

`fgets` 是比 `scanf("%s")` 安全得多的字符串输入方式：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20];

    printf("请输入你的名字：");
    fgets(name, sizeof(name), stdin);

    // fgets 会把换行符也读进来，通常要去掉
    name[strcspn(name, "\n")] = '\0';

    printf("你好，%s！\n", name);
    return 0;
}
```

三个参数的含义是：**存到哪里、最多读多少字节、从哪读**（`stdin` 表示标准输入，也就是键盘）。

`strcspn(name, "\n")` 会返回换行符在字符串中的位置，把那一位改成 `\0`（字符串结束标志），就相当于删掉了换行。

> 顺便说一句：**永远不要用 `gets()`**。它没法限制读入长度，是臭名昭著的缓冲区溢出漏洞来源，C11 标准已经把它从语言里删掉了。

## 五、运算符

### 5.1 算术运算符

```c
int a = 7, b = 2;

printf("%d\n", a + b);   // 9
printf("%d\n", a - b);   // 5
printf("%d\n", a * b);   // 14
printf("%d\n", a / b);   // 3  ← 注意不是 3.5！
printf("%d\n", a % b);   // 1  ← 取余数
```

### 5.2 整数除法与取模：新手的第一个大坑

**两个整数相除，结果还是整数，小数部分被直接丢掉（不是四舍五入）。**

```c
int a = 7, b = 2;
printf("%d\n", a / b);        // 3

double c = 7 / 2;             // 危险！先算 7/2 = 3，再转成 3.0
printf("%.2f\n", c);          // 3.00  ← 不是 3.50

double d = 7.0 / 2;           // 正确：只要有一个是浮点数，结果就是浮点数
printf("%.2f\n", d);          // 3.50

double e = (double)a / b;     // 另一种正确写法：强制转换
printf("%.2f\n", e);          // 3.50
```

**记法：想让除法得到小数，除号两边至少要有一个是小数。**

取模 `%` 只能用于整数，它的典型用途是判断整除和取数字的末位：

```c
if (n % 2 == 0) { /* n 是偶数 */ }

int last_digit = n % 10;    // 取个位
```

### 5.3 关系运算符

```c
a == b    // 等于（注意是两个等号！）
a != b    // 不等于
a > b     // 大于
a < b     // 小于
a >= b    // 大于等于
a <= b    // 小于等于
```

关系运算的结果是整数 `1`（真）或 `0`（假）。

**必须警惕的经典错误：把 `==` 写成 `=`。**

```c
if (a = 5) { ... }    // 这不是比较，而是把 5 赋给 a，然后判断 5 是否为真 → 永远成立
if (a == 5) { ... }   // 正确
```

编译器通常会对第一种写法给出警告。**这就是要加上 `-Wall` 的原因。**

### 5.4 逻辑运算符与短路求值

```c
&&    // 逻辑与：两边都真才为真
||    // 逻辑或：有一个真就为真
!     // 逻辑非：真变假，假变真
```

**短路求值**是个很实用的特性：`&&` 在左边为假时，右边的表达式**根本不会执行**；`||` 在左边为真时，右边也不会执行。

这个特性常用来提前挡住非法访问：

```c
// 先判断下标合法，再访问数组 —— 顺序不能反
if (i >= 0 && i < len && arr[i] > 0) {
    ...
}
```

如果写成 `arr[i] > 0 && i < len`，当 `i` 越界时就会先去访问数组，程序可能直接崩溃。

再比如判断闰年：

```c
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
    printf("%d 是闰年\n", year);
}
```

### 5.5 赋值运算符

```c
a = 10;      // 基本赋值
a += 5;      // 等价于 a = a + 5;
a -= 5;      // a = a - 5;
a *= 2;      // a = a * 2;
a /= 2;      // a = a / 2;
a %= 3;      // a = a % 3;
```

赋值表达式的值就是被赋的那个值，所以可以连写：

```c
int x, y, z;
x = y = z = 0;    // 三个都变成 0
```

### 5.6 自增自减

```c
int i = 5;

int a = i++;    // 先用后加：a = 5，然后 i 变成 6
int b = ++i;    // 先加后用：i 先变成 7，然后 b = 7
```

单独写成一行时，`i++;` 和 `++i;` 没有区别，**在 `for` 循环里用哪个都一样**。

不要在一个表达式里对同一个变量多次自增，这类写法在 C 标准里属于"未定义行为"，不同编译器结果可能不同：

```c
i = i++ + ++i;    // 千万不要这么写
```

### 5.7 三目运算符

```c
条件 ? 值1 : 值2
```

条件为真取值1，否则取值2。它适合写简单的二选一：

```c
int a = 10, b = 20;
int max = (a > b) ? a : b;      // 20
printf("%s\n", (n % 2 == 0) ? "偶数" : "奇数");
```

超过一层嵌套就别用了，老老实实写 `if-else` 更清楚。

### 5.8 位运算符

位运算直接操作二进制位，初学阶段用得不多，但读别人的代码时会遇到：

```c
&    按位与     两个都是 1 才得 1
|    按位或     有一个是 1 就得 1
^    按位异或   两个不同才得 1
~    按位取反   0 变 1，1 变 0
<<   左移       左移 n 位相当于乘 2^n
>>   右移       右移 n 位相当于除以 2^n
```

```c
unsigned int a = 12;    // 二进制 1100
unsigned int b = 10;    // 二进制 1010

printf("%u\n", a & b);   // 1000 → 8
printf("%u\n", a | b);   // 1110 → 14
printf("%u\n", a ^ b);   // 0110 → 6
printf("%u\n", a << 1);  // 11000 → 24
printf("%u\n", a >> 1);  // 110 → 6
```

常见用途是当"开关"用：

```c
#define FLAG_A  (1 << 0)    // 0001
#define FLAG_B  (1 << 1)    // 0010

unsigned int flags = FLAG_A | FLAG_B;   // 同时打开两个标志
if (flags & FLAG_A) { /* FLAG_A 是开着的 */ }
```

### 5.9 运算符优先级

完整优先级表很长，**不要背**。只需要记住三条：

1. `()` 优先级最高 —— **不确定就加括号**；
2. 算术 > 关系 > 逻辑 > 赋值；
3. `!` 和 `++`、`--` 这类一元运算符优先级很高。

一个常被忽略的陷阱：

```c
if (a & 1 == 0)      // 错误理解：以为在判断 a 的奇偶
// 实际等价于 a & (1 == 0)，即 a & 0，永远是 0

if ((a & 1) == 0)    // 正确
```

**只要涉及位运算和比较混用，务必加括号。**

### 5.10 类型转换

**自动转换**（隐式）：小类型遇到大类型时，会自动往大的方向转。

```c
int i = 10;
double d = i;        // 自动变成 10.0，安全
```

反过来则可能丢数据：

```c
double d = 3.99;
int i = d;           // i = 3，小数部分被直接砍掉（不是四舍五入）
```

**强制转换**（显式）：在值前面写 `(目标类型)`。

```c
int total = 7, count = 2;
double avg = (double)total / count;    // 3.5
```

**有符号和无符号混用时要格外小心**：

```c
unsigned int u = 1;
int i = -1;
if (i > u) {
    printf("这行会执行\n");    // 因为 i 被当成无符号数，变成了一个巨大的正数
}
```

看到这类混合比较，**先统一成有符号**再比较，或者干脆全部用 `int`。

## 六、流程控制

### 6.1 if

```c
int score = 85;

if (score >= 60) {
    printf("及格了\n");
}
```

- 条件写在括号里，**不需要分号**（写了分号会让 `if` 作用到一个空语句上，是个隐蔽的坑）；
- 即使只有一条语句，也建议加上 `{}`，方便日后加代码时不出错。

```c
if (score >= 60);        // 危险！这个分号让 if 变空
    printf("及格\n");     // 这行永远会执行
```

### 6.2 else if / else

```c
int score = 85;

if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

判断顺序是从上往下，**一旦某个条件成立，后面的分支就都不再检查了**。所以条件要从严格到宽松排列。

常见的错误是数学式连写：

```c
if (60 <= score < 90)      // 错误！
// 实际含义是 (60 <= score) < 90，即 0<90 或 1<90，永远为真

if (score >= 60 && score < 90)   // 正确
```

### 6.3 switch

当一个变量需要和多组固定值比较时，`switch` 比一长串 `else if` 更清楚：

```c
char grade = 'B';

switch (grade) {
    case 'A':
        printf("优秀\n");
        break;
    case 'B':
        printf("良好\n");
        break;
    case 'C':
        printf("及格\n");
        break;
    default:
        printf("未知等级\n");
        break;
}
```

要点：

- `switch` 的表达式必须是**整数类型**（`int`、`char`、`enum`），不能是浮点数或字符串；
- 每个 `case` 后面必须是**常量**，不能是变量；
- **`break` 不能忘**。忘了它，程序会继续往下执行下一个 `case` 的代码，这叫"穿透"。

穿透偶尔是故意用的，比如让多个月份共用同一段逻辑：

```c
switch (month) {
    case 1: case 3: case 5: case 7:
    case 8: case 10: case 12:
        days = 31;
        break;
    case 4: case 6: case 9: case 11:
        days = 30;
        break;
    case 2:
        // is_leap 是前面算好的闰年标志：1 表示闰年
        days = is_leap ? 29 : 28;
        break;
    default:
        printf("月份不合法\n");
        break;
}
```

### 6.4 while

```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;                 // 别忘了让条件有机会变假，否则是死循环
}
// 输出：1 2 3 4 5
```

适合"不知道要循环几次"的场景：

```c
int n = 12345, count = 0;
while (n > 0) {
    n /= 10;
    count++;             // 每次去掉一位，统计有几位
}
printf("共 %d 位\n", count);   // 5
```

### 6.5 do-while

```c
int n;
do {
    printf("请输入一个正数：");
    scanf("%d", &n);
} while (n <= 0);
```

`do-while` 的特点是**循环体至少执行一次**，因为条件是在末尾检查的。适合"先做一次，再看要不要重做"的输入校验场景。

### 6.6 for

最常用的循环，把"初始化、条件、更新"三件事集中在一行：

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
// 输出：0 1 2 3 4
```

执行顺序是：初始化 → 判断条件 → 执行循环体 → 更新 → 再判断条件 → ……

**用 `for` 遍历数组是最常见的写法**：

```c
int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    printf("arr[%d] = %d\n", i, arr[i]);
}
```

注意条件是 `i < 5` 而不是 `i <= 5`。**数组下标从 0 开始，所以最后一个元素的下标是 长度-1。** 写成 `i <= 5` 就会越界访问。

嵌套循环的例子，打印九九乘法表：

```c
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%-2d ", j, i, i * j);
    }
    printf("\n");
}
```

`for` 的三个部分都可以省略，但分号不能省：

```c
for (;;) { ... }        // 死循环
int i = 0;
for (; i < 5; ) { i++; }  // 也可以这样写，但不推荐
```

### 6.7 break 与 continue

```c
break;      // 立刻跳出整个循环
continue;   // 跳过本次循环剩下的部分，直接开始下一次
```

```c
// 找到第一个能被 7 整除的数就停下
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        printf("找到了：%d\n", i);
        break;
    }
}

// 只打印奇数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;         // 偶数跳过
    }
    printf("%d ", i);
}
```

**注意 `break` 只能跳出它所在的那一层循环。** 嵌套循环里想跳出外层，可以用一个标志变量：

```c
int found = 0;
for (int i = 0; i < 5 && !found; i++) {
    for (int j = 0; j < 5; j++) {
        if (arr[i][j] == target) {
            found = 1;
            break;        // 只跳出内层
        }
    }
}
```

### 6.8 goto

```c
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (arr[i][j] == target) {
            goto found;      // 直接跳到标签处，跳出所有循环
        }
    }
}
found:
    printf("找到了\n");
```

`goto` 能让代码"跳来跳去"，破坏结构，**新手先别用**。它唯一比较正当的用途是跳出多层嵌套循环，以及统一处理错误清理。

## 七、数组

### 7.1 一维数组

数组是**一串相同类型的变量，在内存里挨着排放**，用下标访问：

```c
int arr[5];              // 5 个 int，下标是 0 1 2 3 4

arr[0] = 10;             // 第一个元素
arr[4] = 50;             // 最后一个元素
```

**下标从 0 开始，到 长度-1 结束。** 这一点无论怎么强调都不过分。

### 7.2 初始化方式

```c
int a[5] = {1, 2, 3, 4, 5};    // 完整初始化
int b[5] = {1, 2, 3};          // 只给前三个，剩下两个自动补 0
int c[5] = {0};                // 全部为 0 的常用写法
int d[]  = {1, 2, 3, 4};       // 不写长度，由初始化列表决定（这里长度是 4）

int e[5];
// e 里面是垃圾值，用之前必须先赋值
```

**`int c[5] = {0};` 这个写法要记住**，它是把整个数组清零的最简方式。注意 `{0}` 只写一个 0 就够了，后面的会自动补 0。

### 7.3 遍历

```c
int arr[5] = {10, 20, 30, 40, 50};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum += arr[i];
}
printf("总和 = %d，平均 = %.1f\n", sum, (double)sum / 5);
```

更通用的写法（数组长度变了也不用改）：

```c
int len = sizeof(arr) / sizeof(arr[0]);
for (int i = 0; i < len; i++) { ... }
```

### 7.4 越界：C 语言不会拦你

这是 C 和很多现代语言最大的差别之一：**访问超出范围的数组元素，编译器不会报错，程序也不会立刻崩溃，它只会默默地去读写不属于这块数组的内存。**

```c
int arr[5];
arr[5] = 100;      // 越界！编译能通过，运行时可能崩溃，也可能"看起来正常"
arr[-1] = 100;     // 同样越界
```

后果有三种，全都很糟：

1. 立刻段错误（Segmentation fault）崩溃；
2. 悄悄改坏了别的变量的值，程序行为诡异；
3. 现在看起来没事，改天换个编译器就崩了。

**所以边界检查必须由你自己负责。** 循环条件用 `i < len`，访问前确认下标合法。

### 7.5 二维数组

可以理解成"数组的数组"，常用来表示表格和矩阵：

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// 访问
printf("%d\n", matrix[1][2]);    // 6

// 遍历
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%4d", matrix[i][j]);
    }
    printf("\n");
}
```

初始化时**只有第一维的长度可以省略**：

```c
int m[][3] = {{1,2,3}, {4,5,6}};   // 合法，编译器数出有 2 行
// int m[2][] = {...};             // 非法，第二维必须写
```

### 7.6 字符数组与字符串

C 语言**没有专门的字符串类型**，字符串就是用字符数组存的，并且约定：**以 `\0`（空字符）作为结束标志**。

```c
char s1[6] = {'h', 'e', 'l', 'l', 'o', '\0'};   // 手动加结束符，啰嗦
char s2[6] = "hello";                            // 等价写法，编译器自动加 '\0'
char s3[]  = "hello";                            // 长度自动算成 6
```

`s3` 的长度是 6 而不是 5，因为末尾还有一个 `\0`。**这个 `\0` 不是你打的，是编译器帮你加的。**

这里有个隐蔽的错误：

```c
char s[5] = "hello";      // 合法，但没有位置放 '\0' 了
```

这行**编译能通过**，编译器不会提醒你。但 `s` 已经不算一个合法的字符串了：后面所有依赖 `\0` 的函数（`printf("%s")`、`strlen`、`strcat`）都会一路往后读、越过数组边界，直到内存里碰巧遇到一个 0 才停 —— 结果是打印出一堆乱码甚至崩溃。

**保险的做法是留出结束符的位置：**

```c
char s[6] = "hello";      // 正确
char s[]  = "hello";      // 更好：让编译器自己数
```

**字符串不能直接赋值，也不能用 `==` 比较：**

```c
char a[10] = "hello";
char b[10];

// b = a;              // 错误！数组不能整体赋值
strcpy(b, a);          // 正确：用 strcpy 复制

// if (a == b)         // 错误！这样比的是两个数组的地址，永远不相等
if (strcmp(a, b) == 0) // 正确：用 strcmp 比较内容
```

### 7.7 常用字符串函数

需要 `#include <string.h>`。

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| `strlen(s)` | 求长度（**不含** `\0`） | `strlen("hello")` → 5 |
| `strcpy(d, s)` | 把 s 复制到 d | `strcpy(buf, "abc");` |
| `strncpy(d, s, n)` | 最多复制 n 个字符 | 更安全，但可能没有 `\0` |
| `strcat(d, s)` | 把 s 拼接到 d 后面 | 要求 d 有足够空间 |
| `strcmp(a, b)` | 比较内容 | 相等返回 0，`a<b` 返回负数 |
| `strchr(s, c)` | 查找字符 | 返回指针，找不到返回 `NULL` |
| `strstr(s, sub)` | 查找子串 | 同上 |
| `memset(p, c, n)` | 把 n 个字节设为 c | `memset(arr, 0, sizeof(arr));` |

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char a[20] = "hello";
    char b[] = "world";

    printf("长度：%zu\n", strlen(a));      // 5

    strcat(a, " ");                        // a 变成 "hello "
    strcat(a, b);                          // a 变成 "hello world"
    printf("拼接后：%s\n", a);

    if (strcmp(a, "hello world") == 0) {
        printf("内容相同\n");
    }
    return 0;
}
```

**`strcmp` 的返回值不要拿去和 1 或 -1 比较**，标准只保证"相等时为 0，不等时为正数或负数"。所以判断相等写 `== 0`，判断大小写 `> 0` 或 `< 0`。

## 八、函数

### 8.1 为什么需要函数

当一段逻辑要反复用，或者 `main` 变得很长时，就把它抽成一个函数。好处是：**改一处就够、能重复用、`main` 保持清爽。**

### 8.2 定义、声明、调用

```c
#include <stdio.h>

// 函数声明（原型）：告诉编译器"有这么个函数"
int add(int a, int b);

int main(void) {
    int result = add(3, 5);        // 调用
    printf("3 + 5 = %d\n", result);
    return 0;
}

// 函数定义：真正的实现
int add(int a, int b) {
    return a + b;
}
```

结构拆开看：

```text
int   add  (int a, int b)   { return a + b; }
 ↑     ↑         ↑                  ↑
返回  函数名   参数列表          函数体
类型
```

**关于声明：** 如果函数定义写在 `main` 之前，可以省略声明；如果写在后面，就必须先声明。养成"先声明、后使用"的习惯，代码更易读。

函数名后面的 `()` 里写 `void` 表示"不接收参数"：

```c
void say_hello(void) {
    printf("你好\n");
}
```

`void` 作为返回类型表示"不返回任何值"，此时 `return` 后面不跟东西，或者直接省略。

### 8.3 参数与返回值

```c
// 多个参数用逗号分隔
double average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main(void) {
    printf("%.2f\n", average(80, 90, 100));    // 90.00
    return 0;
}
```

`return` 有两个作用：**把值交回去，并立刻结束这个函数**。函数里 `return` 之后的代码不会执行。

如果一个函数声明了返回类型却没有 `return`，返回值是不确定的 —— 编译器会警告你。

### 8.4 值传递：为什么交换函数不生效

**C 语言的参数传递是"值传递"：函数拿到的是实参的一份拷贝。** 在函数里改参数，不会影响外面的变量。

```c
#include <stdio.h>

void swap_wrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int main(void) {
    int x = 1, y = 2;
    swap_wrong(x, y);
    printf("x = %d, y = %d\n", x, y);   // 还是 1 和 2，没换成
    return 0;
}
```

原因：函数里的 `a`、`b` 只是 `x`、`y` 的副本，改副本不影响原件。

想真正交换，得**传地址**（指针），让函数能直接改到外面的变量：

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);                        // 传的是地址
    printf("x = %d, y = %d\n", x, y);    // x = 2, y = 1
    return 0;
}
```

这是理解指针最重要的一步，第九章会详细展开。

### 8.5 局部变量与全局变量

```c
#include <stdio.h>

int global_count = 0;        // 全局变量：所有函数都能访问

void increase(void) {
    int local = 10;          // 局部变量：只有这个函数内可见
    global_count++;
}

int main(void) {
    increase();
    increase();
    printf("%d\n", global_count);   // 2
    // printf("%d\n", local);       // 错误！local 在这里不存在
    return 0;
}
```

区别：

| | 局部变量 | 全局变量 |
| --- | --- | --- |
| 作用范围 | 只在定义它的函数（或代码块）内 | 整个文件 |
| 未初始化时的值 | **垃圾值** | 自动为 0 |
| 生命周期 | 函数调用结束就销毁 | 程序整个运行期间 |

**全局变量要少用。** 它让任何函数都能偷偷改它，程序一大就很难查问题。优先用参数和返回值传递数据。

### 8.6 static：两个完全不同的用途

**用途一：让局部变量的值"记住"，不被销毁**

```c
#include <stdio.h>

void counter(void) {
    static int count = 0;     // 只初始化一次，之后一直保留
    count++;
    printf("第 %d 次调用\n", count);
}

int main(void) {
    counter();    // 第 1 次调用
    counter();    // 第 2 次调用
    counter();    // 第 3 次调用
    return 0;
}
```

普通局部变量每次函数调用都会重新创建，`static` 局部变量**只在第一次调用时初始化，之后一直存在**。

**用途二：让全局变量或函数只在本文件可见**

```c
static int internal_helper(void) {    // 别的 .c 文件链接不到它
    return 42;
}
```

这用于多文件项目，避免不同文件里的同名函数撞车。

### 8.7 递归

函数调用自己，就叫递归。写递归必须有两部分：

1. **基准情形**：什么时候停下来；
2. **递推关系**：怎么把问题变小。

```c
// 阶乘：n! = n * (n-1)!
long long factorial(int n) {
    if (n <= 1) {           // 基准情形
        return 1;
    }
    return n * factorial(n - 1);   // 递推
}

int main(void) {
    printf("%lld\n", factorial(5));    // 120
    return 0;
}
```

递归的执行过程（以 `factorial(3)` 为例）：

```text
factorial(3) = 3 * factorial(2)
             = 3 * (2 * factorial(1))
             = 3 * (2 * 1)
             = 6
```

**忘记写基准情形，或者基准情形永远到不了，就会无限递归，最终栈溢出崩溃。**

再看一个经典的斐波那契数列 —— 顺便说明**递归不一定高效**：

```c
// 写法简单，但效率极差：计算 fib(40) 要几秒钟
long long fib_slow(int n) {
    if (n <= 1) return n;
    return fib_slow(n - 1) + fib_slow(n - 2);
}

// 循环版本：快得多，推荐
long long fib(int n) {
    if (n <= 1) return n;
    long long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long long t = a + b;
        a = b;
        b = t;
    }
    return b;
}
```

原因在于 `fib_slow` 会把同一项重复计算无数次（算 `fib(40)` 时 `fib(1)` 被算了上亿次）。**递归适合表达"分治"这类天然递归的问题，纯粹的数列计算用循环更好。**

## 九、指针

指针是 C 语言里最让人头疼、但也最核心的概念。这一章慢慢来。

### 9.1 内存与地址

内存可以看成一排连续的字节，每个字节都有一个编号，这个编号就叫**地址**。

变量住在内存里，自然也有地址。指针就是**一个专门用来存放地址的变量**。

```text
变量 n:       [ 42 ]        ← 住在地址 0x7ffd1234
变量 p:       [ 0x7ffd1234 ] ← p 里存的是 n 的地址，所以 p 是指针
```

### 9.2 取地址与解引用

两个核心运算符：

- `&` **取地址**：`&n` 得到 n 的地址；
- `*` **解引用**：`*p` 得到 p 指向的那个变量的值。

```c
#include <stdio.h>

int main(void) {
    int n = 42;
    int *p = &n;             // p 指向 n

    printf("n 的值    : %d\n", n);      // 42
    printf("n 的地址  : %p\n", (void *)&n);
    printf("p 里存的  : %p\n", (void *)p);   // 和上面一样
    printf("*p 的值   : %d\n", *p);     // 42

    *p = 100;                // 通过指针修改 n
    printf("现在 n 是 : %d\n", n);      // 100
    return 0;
}
```

**关键理解：`*p` 就是 `n` 本身，只是换了个名字。** 通过 `*p` 改值，`n` 跟着变。

注意声明里的 `*` 和用的时候的 `*` 含义不同：

```c
int *p = &n;    // 这里的 * 是"声明 p 是一个指针"
*p = 100;       // 这里的 * 是"解引用，取 p 指向的内容"
```

### 9.3 指针的类型

指针必须写清楚它指向什么类型：

```c
int *pi;        // 指向 int 的指针
double *pd;     // 指向 double 的指针
char *pc;       // 指向 char 的指针
```

指针的类型决定了**解引用时读几个字节**，以及**指针加 1 时跳过几个字节**：

```c
int arr[3] = {10, 20, 30};
int *p = arr;

printf("%d\n", *p);        // 10
printf("%d\n", *(p + 1));  // 20  ← p+1 跳过了一整个 int（4 字节），不是 1 字节
```

### 9.4 指针与数组

**数组名在大多数情况下会"退化"成指向第一个元素的指针。**

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;          // 等价于 int *p = &arr[0];

// 下面四种写法完全等价
printf("%d\n", arr[2]);      // 30
printf("%d\n", *(arr + 2));  // 30
printf("%d\n", p[2]);        // 30
printf("%d\n", *(p + 2));    // 30
```

**`arr[i]` 本质上就是 `*(arr + i)` 的简写。** 理解这一点，指针和数组就打通了。

用指针遍历数组：

```c
int arr[5] = {10, 20, 30, 40, 50};
int len = sizeof(arr) / sizeof(arr[0]);

for (int *p = arr; p < arr + len; p++) {
    printf("%d ", *p);
}
```

**但数组名不是指针**，有两个重要区别：

```c
int arr[5];

sizeof(arr)        // 20：整个数组的大小
// arr = something // 错误！数组名不能被赋值（它不是左值）
```

**还有一个必须知道的陷阱**：数组作为函数参数时，会退化成指针，所以**在函数内部用 `sizeof` 求不出数组长度**：

```c
void print_len(int arr[]) {          // 这里 int arr[] 实际就是 int *arr
    printf("%zu\n", sizeof(arr));    // 8（一个指针的大小），不是 20！
}

int main(void) {
    int arr[5];
    printf("%zu\n", sizeof(arr));    // 20
    print_len(arr);
    return 0;
}
```

**所以数组传给函数时，必须额外传一个长度参数**：

```c
void print_array(const int arr[], int len) {
    for (int i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// 调用
print_array(arr, sizeof(arr) / sizeof(arr[0]));
```

参数里的 `const` 表示"这个函数不会修改数组内容"，是很好的自我说明，也能让编译器帮你挡住误改。

### 9.5 指针作为函数参数

这是指针最实用的地方：**让函数能修改调用者的变量**。

```c
// 返回两个数中的最大值，同时通过指针"带回"最小值
int max_and_min(int a, int b, int *min_out) {
    if (a > b) {
        *min_out = b;
        return a;
    } else {
        *min_out = a;
        return b;
    }
}

int main(void) {
    int min;
    int max = max_and_min(10, 20, &min);
    printf("最大 %d，最小 %d\n", max, min);    // 最大 20，最小 10
    return 0;
}
```

因为 C 的函数只能 `return` 一个值，需要"返回多个结果"时，就用指针参数把额外的结果写回去。

### 9.6 NULL 与野指针

**野指针**：指向了无效位置的指针。它是 C 程序崩溃的头号原因。

```c
int *p;          // 未初始化，p 里是垃圾值
*p = 10;         // 危险！往一个随机地址写数据 → 段错误
```

三种典型的野指针来源：

```c
int *p1;                      // ① 声明了没初始化
int *p2 = malloc(...); free(p2); *p2 = 1;   // ② 释放后继续用
int *p3 = NULL; *p3 = 1;      // ③ 解引用空指针
```

**防御手段：**

```c
int *p = NULL;               // ① 声明时就初始化成 NULL

if (p != NULL) {             // ② 用之前检查
    *p = 10;
}

free(p);                     // ③ 释放之后立刻置空
p = NULL;
```

`NULL` 是一个表示"不指向任何地方"的特殊值，定义在 `<stdio.h>`、`<stdlib.h>`、`<string.h>` 等头文件里。

### 9.7 指针与字符串

字符串常量本质上是一个字符数组，用指针指向它：

```c
char *s = "hello";
printf("%s\n", s);        // hello
printf("%c\n", s[0]);     // h
printf("%c\n", *(s + 1)); // e
```

**但字符串常量是只读的，不能修改：**

```c
char *s = "hello";
s[0] = 'H';               // 未定义行为！可能崩溃
```

想要能修改，就用数组：

```c
char s[] = "hello";       // 拷贝了一份到可写的数组里
s[0] = 'H';               // 合法，s 变成 "Hello"
```

两者的区别：

```c
char *p = "hello";        // 指向只读的字符串常量，不能改
char a[] = "hello";       // 一个可读写的数组，可以改
```

### 9.8 二级指针（了解即可）

指向指针的指针：

```c
int n = 42;
int *p = &n;
int **pp = &p;            // pp 指向 p

printf("%d\n", **pp);     // 42
```

初学阶段遇到的机会不多，知道有这么回事就行。它主要出现在"需要在函数里修改一个指针本身"的场景（比如动态数组扩容）。

## 十、结构体、枚举、联合

### 10.1 结构体：把不同类型的数据打包

数组要求所有元素类型相同。如果想把"姓名 + 年龄 + 成绩"放在一起，就需要结构体：

```c
#include <stdio.h>

struct Student {
    char name[20];
    int age;
    double score;
};

int main(void) {
    // 声明并初始化
    struct Student s1 = {"小明", 18, 92.5};

    // 逐个访问成员，用点号
    printf("姓名：%s\n", s1.name);
    printf("年龄：%d\n", s1.age);
    printf("成绩：%.1f\n", s1.score);

    // 修改成员
    s1.score = 95.0;

    // 结构体可以整体赋值
    struct Student s2 = s1;
    printf("%s\n", s2.name);      // 小明
    return 0;
}
```

注意 `s1.name` 是数组，**不能写成 `s1.name = "小红";`**，要用 `strcpy`：

```c
strcpy(s1.name, "小红");
```

结构体数组也很常用：

```c
struct Student class1[3] = {
    {"小明", 18, 92.5},
    {"小红", 19, 88.0},
    {"小刚", 18, 76.5}
};

for (int i = 0; i < 3; i++) {
    printf("%-8s %d 岁 %.1f 分\n", class1[i].name, class1[i].age, class1[i].score);
}
```

### 10.2 结构体指针与 `->`

当结构体作为函数参数时，传指针可以避免复制整个结构体，效率更高。访问成员时用 `->` 代替 `.`：

```c
void print_student(const struct Student *s) {
    printf("%s %d %.1f\n", s->name, s->age, s->score);
    // s->name 等价于 (*s).name
}

int main(void) {
    struct Student s1 = {"小明", 18, 92.5};
    print_student(&s1);
    return 0;
}
```

记忆方法：**手里是结构体本身就用 `.`，手里是指针就用 `->`。**

### 10.3 typedef：给类型起别名

```c
typedef struct Student Student;    // 之后可以写 Student 而不用写 struct Student

typedef struct {
    int x;
    int y;
} Point;                            // 定义的同时起别名，最常用的写法
```

现在用起来清爽多了：

```c
Student s1 = {"小明", 18, 92.5};
Point p = {3, 4};
```

### 10.4 枚举：给整数起名字

```c
enum Weekday {
    MON = 1, TUE, WED, THU, FRI, SAT, SUN
};

int main(void) {
    enum Weekday today = WED;
    printf("%d\n", today);        // 3
    return 0;
}
```

规则：

- 如果不指定值，第一个成员是 0，之后依次加 1；
- 上面手动让 `MON = 1`，所以 `SUN` 就是 7；
- 枚举成员本质上是整数常量，可以直接和 `int` 比较，也能用在 `switch` 里。

枚举的价值是**可读性**：`if (today == SAT || today == SUN)` 比 `if (today == 6 || today == 7)` 清楚得多。

### 10.5 联合：共用一块内存

```c
union Data {
    int i;
    float f;
    char str[8];
};

int main(void) {
    union Data d;
    printf("%zu\n", sizeof(d));    // 8，等于最大成员的大小

    d.i = 10;                      // 写入 i
    printf("%d\n", d.i);           // 10

    d.f = 3.14f;                   // 写入 f 会覆盖同一块内存，i 的值就废了
    return 0;
}
```

`union` 的所有成员**共用同一块内存**，同一时刻只有一个成员是有效的。它主要用于节省内存，以及查看数据的底层字节表示。初学阶段知道概念即可。

## 十一、动态内存

### 11.1 为什么需要

前面所有变量的大小在编译时就已经定死了：

```c
int arr[100];      // 最多 100 个，用户想存 200 个怎么办？
```

如果写成 `int arr[1000000];`，又会白白浪费内存。**动态内存分配让程序在运行时才决定要多少内存。**

### 11.2 四个函数

需要 `#include <stdlib.h>`。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;

    printf("要存几个数？");
    scanf("%d", &n);

    // 申请 n 个 int 的空间
    int *arr = malloc(n * sizeof(int));
    if (arr == NULL) {                 // 一定要检查是否成功
        printf("内存申请失败\n");
        return 1;
    }

    // 当普通数组一样用
    for (int i = 0; i < n; i++) {
        arr[i] = i * i;
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);                         // 用完必须还回去
    arr = NULL;                        // 防止变成野指针
    return 0;
}
```

四个函数的区别：

| 函数 | 作用 |
| --- | --- |
| `malloc(size)` | 申请 `size` 字节，**内容不确定** |
| `calloc(n, size)` | 申请 `n × size` 字节，**自动清零** |
| `realloc(p, size)` | 把已申请的内存调整成 `size` 字节 |
| `free(p)` | 释放内存 |

`malloc(n * sizeof(int))` 这个写法**要背下来**：它自动适应不同平台上 `int` 的大小，比手写 `malloc(n * 4)` 可靠。

`realloc` 的正确用法（**不能直接覆盖原指针**）：

```c
int *bigger = realloc(arr, new_n * sizeof(int));
if (bigger == NULL) {
    // 申请失败时，原来的 arr 依然有效，需要自己处理
    free(arr);
    return 1;
}
arr = bigger;
```

如果写成 `arr = realloc(arr, ...)` 而它失败了，原来那块内存的地址就丢了，造成内存泄漏。

### 11.3 三个经典错误

**① 内存泄漏：申请了不还**

```c
void leak(void) {
    int *p = malloc(100 * sizeof(int));
    // 函数结束，p 这个指针没了，但申请的内存还在 → 泄漏
}
```

程序长时间运行会越吃越多内存，最终被系统杀掉。**规则：每个 `malloc` 都要有对应的 `free`。**

**② 悬空指针：还了继续用**

```c
int *p = malloc(sizeof(int));
*p = 10;
free(p);
printf("%d\n", *p);     // 未定义行为！这块内存已经不属于你了
p = NULL;               // 正确做法：free 之后立刻置空
```

**③ 重复释放**

```c
int *p = malloc(sizeof(int));
free(p);
free(p);                // 崩溃！同一块内存不能释放两次
```

这也是为什么强调 `free` 之后要 `p = NULL` —— `free(NULL)` 是安全的（什么都不做），所以置空可以避免重复释放。

## 十二、预处理

以 `#` 开头的指令在**编译之前**由预处理器处理。它们不是 C 语句，结尾不加分号。

### 12.1 #include

```c
#include <stdio.h>      // 尖括号：从系统标准目录查找
#include "myheader.h"   // 双引号：先找当前目录，再找系统目录
```

所以：**标准库用尖括号，自己写的头文件用双引号。**

### 12.2 #define

```c
#define PI 3.14159
#define MAX_SIZE 100
#define SQUARE(x) ((x) * (x))
```

习惯上宏名全大写，方便一眼认出。它做的是**纯文本替换**，没有类型检查。

### 12.3 宏的坑：为什么括号不能省

```c
#define SQUARE(x) x * x

SQUARE(1 + 2)      // 展开成 1 + 2 * 1 + 2 = 5，而不是期望的 9
```

加上括号就对了：

```c
#define SQUARE(x) ((x) * (x))     // 展开成 ((1 + 2) * (1 + 2)) = 9
```

**写带参数的宏，每个参数和整个表达式都要用括号包起来。**

正因为宏有这些陷阱，**能用 `const` 和函数就不要用宏**：

```c
const double PI = 3.14159;          // 优于 #define PI 3.14159

double square(double x) { return x * x; }   // 优于 #define SQUARE(x)
```

### 12.4 条件编译

可以根据条件决定"编译哪几段代码"：

```c
#define DEBUG 1

int main(void) {
#ifdef DEBUG
    printf("调试信息：程序开始运行\n");
#endif
    return 0;
}
```

常用的三种：

```c
#ifdef NAME      // 如果定义了 NAME
#ifndef NAME     // 如果没定义 NAME
#if 表达式       // 表达式为真
```

一个典型用途是**头文件卫士**，防止同一个头文件被重复包含：

```c
#ifndef MYHEADER_H
#define MYHEADER_H

// 头文件内容写在这里

#endif
```

### 12.5 多文件编译

项目变大后，代码会拆成多个文件。假设有三个文件：

```c
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int sub(int a, int b);

#endif
```

```c
// math_utils.c
#include "math_utils.h"

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
```

```c
// main.c
#include <stdio.h>
#include "math_utils.h"

int main(void) {
    printf("%d\n", add(3, 5));
    return 0;
}
```

编译时把 `.c` 文件都列上：

```bash
gcc -Wall -Wextra -std=c17 main.c math_utils.c -o app
```

**注意：头文件（`.h`）只放声明，`.c` 文件放实现。** 不要在头文件里写函数体，否则多个文件包含它时会出现重复定义的链接错误。

## 十三、怎么读懂编译器的报错

新手看到满屏报错就慌，其实只要掌握几条规律：

**规律一：报错信息要"从第一条看起"。** 后面的错误往往是第一条的连锁反应。改掉第一条，重新编译，可能剩下的都消失了。

**规律二：看行号和列号。** 编译器会指出 `hello.c:7:5` 这样的位置。注意有时**真正的问题在上一行**（比如上一行漏了分号，编译器到下一行才发现）。

**规律三：区分 warning 和 error。**

- `warning`：能编译，但可能有问题，**也要修**；
- `error`：编译不通过，必须修。

下面是几个最常见的报错，认脸就行：

**① 漏了分号**

```text
error: expected ';' before '}' token
```

**② 变量名拼错**

```text
error: 'count' undeclared (first use in this function)
```

意思是"没有叫 count 的变量"。检查拼写，或者是不是忘了声明。

**③ 格式符和参数类型不匹配**

```text
warning: format '%d' expects argument of type 'int',
         but argument 2 has type 'double'
```

把 `%d` 改成 `%f`。

**④ 忘了包含头文件**

```text
warning: implicit declaration of function 'printf'
```

看到 `implicit declaration`，基本就是忘了 `#include`。

**⑤ 链接错误：找不到函数实现**

```text
undefined reference to `sqrt'
```

`sqrt` 在数学库里，Linux 下要加 `-lm`：

```bash
gcc main.c -o app -lm
```

**⑥ 段错误（Segmentation fault）**

注意这几个字通常**不是编译器的报错，而是程序运行到一半崩了**。常见原因是：

- 数组越界；
- 用了野指针或 `NULL` 指针；
- `scanf` 忘了写 `&`；
- 递归太深导致栈溢出。

**调试段错误的最快办法是加打印**，在可疑的位置前后各打一行，看它在哪一步崩的：

```c
printf("=== 准备访问 arr[%d]\n", i);
arr[i] = 1;
printf("=== arr[%d] 赋值完成\n", i);
```

进阶之后可以学 `gdb`（Linux/macOS）或 Visual Studio 的调试器，能直接看到崩溃时的调用栈。

## 十四、新手最常踩的 15 个坑（速查表）

| # | 坑 | 正确做法 |
| --- | --- | --- |
| 1 | 把 `==` 写成 `=` | 条件里比较用两个等号 |
| 2 | 漏分号 | 每条语句结尾加分号，但 `#include`、`if(...)` 后不加 |
| 3 | 数组越界 | 循环写 `i < len`，最后一个是 `len-1` |
| 4 | `scanf` 漏 `&` | 除数组名外都要加 `&` |
| 5 | 整数除法丢小数 | 写成 `(double)a / b` |
| 6 | 变量没初始化 | 声明时就给初值，尤其是累加器写 `sum = 0` |
| 7 | 字符串没有 `\0` | 数组长度要 +1；用 `fgets` 而不是 `gets` |
| 8 | `scanf("%s")` 溢出 | 写成 `scanf("%9s", buf)` |
| 9 | 浮点数用 `==` 比较 | 用 `fabs(a - b) < 1e-9` |
| 10 | `switch` 忘了 `break` | 每个 `case` 结束都检查一遍 |
| 11 | 数学式连写 `a < b < c` | 写成 `a < b && b < c` |
| 12 | `free` 之后继续用 | `free(p); p = NULL;` |
| 13 | `for` 循环里改了循环变量 | 别在循环体里手动改 `i` |
| 14 | 数组传参后求 `sizeof` | 额外传一个长度参数 |
| 15 | 忘了重新编译 | 改完代码先编译再运行 |

## 十五、练习题

从易到难，建议动手写，不要只看。

**1. 圆的面积和周长**

输入半径，输出面积和周长（保留两位小数）。提示：`#define PI 3.14159`，注意用 `%lf` 读 `double`。

**2. 判断闰年**

输入年份，判断是否闰年。提示：`(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`。

**3. 九九乘法表**

用两层循环打印九九乘法表。提示：外层 `i` 从 1 到 9，内层 `j` 从 1 到 `i`。

**4. 求最大值和最小值**

输入 10 个数存进数组，输出最大值、最小值和平均值。提示：先把 `max` 和 `min` 都设成 `arr[0]`，再从 `arr[1]` 开始比。

**5. 数组逆序**

把数组里的元素倒过来存放，然后输出。提示：用两个下标 `i` 和 `j = len-1` 向中间靠拢，交换 `arr[i]` 和 `arr[j]`。

**6. 统计字符**

输入一行字符串，统计其中字母、数字、空格和其他字符各有多少个。提示：用 `fgets` 读入，遍历时用 `<ctype.h>` 里的 `isalpha()`、`isdigit()`、`isspace()`。

**7. 判断素数**

输入一个整数，判断是不是素数。提示：从 2 试到 `sqrt(n)` 就够，需要 `#include <math.h>` 并加 `-lm`。

**8. 最大公约数**

用辗转相除法求两个数的最大公约数。提示：`while (b != 0) { t = a % b; a = b; b = t; }`，最后 `a` 就是答案。

**9. 冒泡排序**

把数组从小到大排序。提示：两层循环，内层比较相邻两个元素，逆序就交换。

**10. 递归求阶乘**

用递归函数计算 `n!`，并注意 `n` 稍大就会超出 `int` 的范围（试试 `long long`）。

**11. 学生成绩管理**

用结构体数组存 5 个学生的姓名、学号、三门课成绩，计算每人总分，并按总分从高到低排序输出。提示：把第八章的结构体和第九章的排序结合起来，交换整个结构体用 `=` 整体赋值即可。

**12. 动态数组**

让用户先输入 `n`，再输入 `n` 个整数，用 `malloc` 动态申请内存，排序后输出，最后 `free`。提示：别忘了检查 `malloc` 是否返回 `NULL`。

## 十六、接下来学什么

把上面这些掌握之后，你已经能写出几百行、结构清晰的 C 程序了。之后可以按这个顺序继续：

1. **文件操作**：`fopen`、`fread`、`fwrite`、`fclose`，让程序能读写文件而不是只在终端里跑；
2. **指针进阶**：函数指针、指针数组、二级指针，理解 C 的"回调"写法；
3. **数据结构**：链表、栈、队列、二叉树 —— 这些用 C 手写一遍，对指针的理解会彻底打通；
4. **调试工具**：`gdb` 单步调试，`valgrind` 检测内存泄漏（Linux/macOS），Windows 上用 Visual Studio 的调试器；
5. **构建工具**：当文件多起来，手敲 `gcc` 会烦，用 `Makefile` 或 `CMake` 管理；
6. **读别人的代码**：找一个感兴趣的小型开源项目（比如一个小型解释器或游戏），读它的源码，收获会很大。

最后一句建议：**C 语言是一门"你要为每一步负责"的语言**。它不会替你检查数组越界，也不会替你回收内存，但正因如此，学完它你会真正理解"程序在内存里是怎么跑的"——这份理解对之后学任何语言都有用。

祝你写码顺利。
